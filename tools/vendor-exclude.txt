# TUs bg3le does not build: either replaced by its own implementation or
# client-UI code that is not a target yet. Used by tools/check-vendor-all.sh
# to separate real remaining work from files that will never be compiled.
#
# The symbol mapper scans PE images; bg3le reads the ELF symbol table.
# The Osiris wrappers and EngineHooks inline-hook via Detours; bg3le uses PLT
# interposition, vtable slot patching and call-site patching.
# dllmain/CrashReporter/DWriteWrapper are Windows process plumbing.
# CoreLib/Console.cpp is a Windows console, down to font and colour tables.
# IMGUI.cpp compiles here unchanged; what it cannot do is link, because it is
# written against bg3se Lua binding framework rather than against Lua. See
# reference/IMGUI-ASSESSMENT.md for the symbol list and what bg3le own
# implementation would take.
